# Translation review

Every Hindi (hi), Marathi (mr), Tamil (ta) and Telugu (te) string in Promo-Flow is **machine-drafted** and has not been checked by a
native speaker. English (en) is the source. Ask a native speaker to read the whole table before the extension is shown to real users,
and fix the strings in `src/i18n/<lang>.json` (the key-parity test keeps all languages in step).

Please pay particular attention to the strings about money, login, CAPTCHA and removed coupons, because a wrong word there could mislead.

The app name and description in `_locales/<lang>/messages.json` are also machine-drafted.
